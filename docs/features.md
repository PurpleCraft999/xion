

### Names
A name is any character in a-Z 0-9 or an underscore however it cannot start with a number


### Var declarations

declaring a variable must start with let and end witha semicolon

```
let <name> = <value>;
```
### Function declarations

keyword fn followed by na

```xion
fn <name>(<values>){

    <body>

}
```

## Classes

### Class declarations

body can have functions and variables

}
